### 복습: 반복

```c
int main(void)
{
	int i, result = 0;
	for (i = 1; i <= 10; i = i + 1) {
		result = result + i;
	}
	return 0;
}
```

반복 문장:  

```c
for    (    수식    ;    수식    ;    수식    )    문장
```
