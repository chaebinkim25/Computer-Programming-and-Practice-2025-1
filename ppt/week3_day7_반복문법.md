### 반복해서 실행하기: for 문장

```c
int main(void)
{
	int i, state = 0;
	for (i = 0; i < 3; i = i + 1) {
		state = i;
	}
	return 0;
}
```

`for` 문장:  

```c
for    (    수식    ;    수식    ;    수식    )    문장
```
