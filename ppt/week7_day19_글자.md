### 복습: 컴퓨터란 무엇일까?

컴퓨터는 CPU와 메모리다

- CPU는 계산기다
- 메모리는 저장소다

---

### 복습: 코드란 무엇일까?

코드는 컴퓨터 작업의 최소 단위다

- CPU가 어떤 작업을 할지 정한다
- 메모리의 특정 주소에 작업 결과를 저장한다

---

### 복습: 프로그램이란 무엇일까?

프로그램은 코드를 조합해서 작업을 하는 것이다 

- 메모리에 코드들을 나열한다
- CPU는 저장된 코드들을 순서대로 실행한다

---

### 복습: 조금 더 복잡한 프로그램을 짜려면?

다음에 실행할 코드를 바꾸는 코드를 쓴다

- 이전으로 이동하면 반복할 수 있다
- 이후로 이동하면 건너뛸 수 있다
- 조건에 따라 실행할 코드를 바꿀 수도 있다

---

### 복습: 매우 복잡한 프로그램을 짜려면?

해야 할 작업을 나눠서 코드를 만든다

- 각 코드는 결과값을 만든다
- 다른 코드가 만든 결과값을 활용할 수 있다

---

### 복습: 프로그래밍 실습을 쉽게 하려면?

프로그래밍 언어로 코드들을 만든다

- 기계어 대신 영어와 수학 기호를 쓴다
- 자주 쓰이는 코드를 완벽하게 만들어서 제공한다

### 문장을 저장하는 코드

```c
#include <stdio.h>
int main(void)
{
	char hi[3] = {'H', 'i', '\0'};
	for (int i = 0; hi[i] != '\0'; i++) {
		putchar(hi[i]);
	}
	return 0;
}
```

### 문장을 저장하고 쓰는 코드

```c
#include <stdio.h>
int main(void)
{
	char *hi = "Hi";
	for (int i = 0; hi[i] != '\0'; i++) {
		putchar(hi[i]);
	}
	return 0;
}
```

저장된 글자를 변경하면 안된다!
