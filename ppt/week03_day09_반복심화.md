### 보안 취약점: 제어를 벗어난 반복

다음 코드에서 공격받을 수 있는 방법은?

```c
int i;
int user_request = 0;
/* user_request를 입력받는다 */
for (i = 0; i < user_request; i += 1) {
	/* 무거운 연산 실행 */
}
```

---

### 보안 취약점: 타이밍 노출

다음 코드에서 공격받을 수 있는 방법은?

```c
int i;
int secret_digit = 1, guess_digit;
for (i = 0; i < 4; i += 1) {
	/* secret_digit과 guess_digit 계산 */
	if (secret_digit != guess_digit) {
		break;
	}
}
```

---

### 보안 취약점: 잘못된 비교

다음 코드에서 무한 루프가 발생하는 경우는?

```c
int i;
int target = 0;
/* target 계산 */
for (i = 0; i != target; i = i + 2) {
	/* ... */
}
```

---

### 보안 취약점: 도달할 수 없는 반복

다음 코드를 실행했을 때 일어나는 일은?

```c
int highest_factor = 1;
int target = 0;
/* target 계산 */
for (i = 2; i < target; i += 1) {
	if (target % i == 0) {
		highest_factor = i;
	}
	break;
}
```

---

### 보안 취약점: 너무 이른 종료

다음 코드를 실행했을 때 일어나는 일은?

```c
int height = 0, speed = 100, gravity = 10;
int time_steps = 0, i;
for (i = 0; i < 100; i += 1) {
	height = height + speed;
	speed = speed - gravity;
	if (height <= 0) {
		break;
	}
	time_steps = time_steps + 1;
}
```
