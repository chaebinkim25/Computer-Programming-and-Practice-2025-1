### 복습: 헤더 파일이란 무엇인가?

헤더 파일에는 함수의 헤더를 등록해놓았다.

- 함수의 헤더는 반환타입, 이름, 입력정보다.

---

### 복습: `stdio.h` 헤더 파일의 내용은?

입력과 출력에 관련된 함수 헤더들이 있다.

```c
int putchar (int __c);
int getchar (void);
```

---

### 복습: 헤더 파일을 복사해오는 방법은?

`#include <stdio.h>`로 표준입출력 함수 헤더들을 가져온다.

### 문장을 입력받는 함수 만들기 - 코드

```c
void scan(char *buffer, int size)
{
	int i;
	for (i = 0; i < size - 1; i++) {
		buffer[i] = getchar();
		if (buffer[i] == '\n') break;
	}
	buffer[i] = '\0';
}
```
